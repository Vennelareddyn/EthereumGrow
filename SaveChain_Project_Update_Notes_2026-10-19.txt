6. SAVINGS GOAL AND WITHDRAWAL ERROR
============================================================

The dashboard showed:

Savings goal: 0.001 ETH
Total saved: 0 ETH

A withdrawal was attempted for:
0.0001 ETH

The error included:
execution reverted (unknown custom error)
action="estimateGas"
data="0xcd280f65"
code=CALL_EXCEPTION

The transaction data began:
0x2e1a7d4d00000000000000000000000000000000000000000000000000005af3107a4000

The function selector 0x2e1a7d4d corresponds to withdraw(uint256), and the encoded amount is 100,000,000,000,000 wei = 0.0001 ETH.

The contract's withdrawal logic checks:
1. The amount is not zero.
2. The caller's recorded savings are at least the requested amount.
3. It subtracts the amount from savings.
4. It sends ETH to the caller.
5. It reverts if the transfer fails.

Since the dashboard showed Total saved = 0 ETH, the failure is consistent with InsufficientSavings(). However, the returned error data 0xcd280f65 has not yet been definitively decoded, so do not assume this is the confirmed error until the on-chain mapping value is checked.

The failure occurred during gas estimation. Normally, if a transaction is rejected during estimation and is never submitted, no withdrawal transaction is mined and no withdrawal transaction gas fee is charged.

============================================================
7. IMPORTANT: WALLET ETH VS. SAVECHAIN SAVINGS
============================================================

These are two different balances:

Wallet ETH balance:
ETH held by the wallet address on Sepolia.

SaveChain savings:
The amount recorded for the wallet inside the deployed contract's mapping:
savings[walletAddress]

The wallet can have ETH while SaveChain records zero savings. The contract's goal mapping is also separate:
savingsGoal[walletAddress]

A savings goal of 0.001 ETH does not automatically deposit 0.001 ETH. The user must make a successful deposit transaction.
